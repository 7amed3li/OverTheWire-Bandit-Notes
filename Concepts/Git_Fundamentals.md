# 🌿 Git Fundamentals for Security

## 🇺🇸 English

Git is a distributed version control system that tracks changes in code. For security professionals, understanding Git is crucial because:

1. **History Never Forgets**: Even if a developer removes sensitive data, it remains in the commit history
2. **Branches Hide Secrets**: Development branches may contain credentials not meant for production
3. **Tags Store Data**: Tags can store arbitrary data, not just version markers

### Essential Commands

| Command | Purpose |
|---------|---------|
| `git clone` | Download a repository |
| `git log` | View commit history |
| `git show <hash>` | View commit details |
| `git branch -a` | List all branches |
| `git checkout <branch>` | Switch branches |
| `git tag` | List all tags |

---

## 🇪🇬 العربية

Git هو نظام للتحكم في الإصدارات. بالنسبة لخبراء الأمن، فهم Git ضروري لأن:

1. **التاريخ لا يُنسى**: حتى لو حذف المطور بيانات حساسة، تظل في سجل الـ commits
2. **الفروع تخفي الأسرار**: فروع التطوير قد تحتوي على بيانات اعتماد غير مخصصة للإنتاج
3. **العلامات تخزن البيانات**: العلامات (Tags) يمكن أن تخزن بيانات، وليس فقط علامات الإصدار

### بالبلدي
- **Clone**: زي ما تنسخ فولدر كامل من جهاز صاحبك
- **Log**: زي دفتر الحضور، بيسجل كل حاجة اتعملت
- **Branch**: زي نسخة تجريبية من المشروع بتجرب فيها حاجات جديدة

## 🇹🇷 Türkçe

Git, koddaki değişiklikleri takip eden dağıtılmış bir sürüm kontrol sistemidir. Güvenlik uzmanları için Git'i anlamak çok önemlidir çünkü:

1. **Tarih Asla Unutmaz**: Bir geliştirici hassas verileri silse bile, commit geçmişinde kalır
2. **Dallar Sırları Gizler**: Geliştirme dalları, üretim için tasarlanmamış kimlik bilgilerini içerebilir
3. **Etiketler Veri Depolar**: Etiketler sadece sürüm işaretleyicileri değil, rastgele veriler de depolayabilir

### Temel Komutlar

| Komut | Amaç |
|-------|------|
| `git clone` | Depoyu indir |
| `git log` | Commit geçmişini görüntüle |
| `git show <hash>` | Commit detaylarını göster |
| `git branch -a` | Tüm dalları listele |
| `git checkout <dal>` | Dal değiştir |
| `git tag` | Tüm etiketleri listele |
