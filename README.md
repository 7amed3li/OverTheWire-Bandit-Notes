This repository contains a comprehensive, methodology-focused educational guide for the **OverTheWire Bandit wargame**. Unlike traditional write-ups that provide direct solutions, this guide documents the entire problem-solving journey, including failures, error analysis, and the step-by-step thought process of a security learner.

The content is presented in a parallel bilingual format (**Arabic** and **Turkish**) and is designed to be exceptionally beginner-friendly.

### :thinking: The Philosophy: Methodology Over Memorization

The primary goal of this project is not just to solve the levels, but to teach the "hacker mindset":
- **Analyze** the problem before writing any commands.
- **Formulate** a plan and anticipate potential issues.
- **Execute** the plan and meticulously document the results.
- **Learn from errors** by understanding why they happened.
- **Master the tools** by understanding their core functions, not just their flags.

### :gem: The Best Viewing Experience: Using Obsidian

This project was created and is best viewed using **Obsidian**.

**What is Obsidian?**
[Obsidian](https://obsidian.md/ ) is a powerful and free knowledge base application that works on local Markdown files. It allows you to create a "second brain" by linking notes, visualizing connections, and navigating your knowledge seamlessly.

**Why use Obsidian for this guide?**
- **Internal Linking:** The guide uses `[[wiki-links]]` to connect levels, concepts, and solutions, allowing you to navigate the entire project effortlessly.
- **Image Display:** All screenshots and diagrams are embedded directly in the notes and will display correctly.
- **Clean Reading Experience:** Obsidian provides a beautiful, distraction-free interface for reading Markdown files.
- **It's Free and Offline:** Your data stays on your machine.

### :rocket: How to Use This Guide

Follow these simple steps to get the best experience:

**Step 1: Download and Install Obsidian**
- Go to the official website: [obsidian.md](https://obsidian.md/ )
- Download and install the version for your operating system (Windows, macOS, Linux).

**Step 2: Download This Project**
- Click the green `<> Code` button at the top of this GitHub page.
- Select `Download ZIP`.
- Unzip the downloaded file (`Bandit-OverTheWire-Guide-main.zip` or similar) to a location of your choice on your computer.

**Step 3: Open the Project in Obsidian**
1.  Open the Obsidian application.
2.  On the launch screen, click on **"Open folder as vault"**.
3.  Navigate to the folder you unzipped in the previous step and select it.
4.  That's it! You can now browse all the level guides, view the images, and click on the internal links to jump between notes.
