# Contributing to Bandit OverTheWire Masterclass

First off, thank you for considering contributing to this repository! It's people like you that make the cybersecurity community great.

## How to Contribute

### 1. Adding/Improving Level Solutions

- Every solution should follow the trilingual format (Arabic, English, Turkish).
- Focus on the **Methodology** and **Learning** aspect, not just the password.
- Use clear, professional, and educational language.

### 2. Adding Concept Notes

- If you find a topic that is frequently used in Bandit but isn't explained (e.g., Cryptography, Networking), please create a new note in the `Concepts/` directory.

### 3. Translations

- If you see a solution or concept that is missing a translation or has a poor one, feel free to submit a fix!

## Pull Request Process

1. Fork the repository.
2. Create a specific branch for your changes (e.g., `feature/new-level-translation`).
3. Ensure your Markdown is properly formatted for Obsidian.
4. Submit your Pull Request with a clear description of what you added or changed.

## Style Guide

- Use GitHub Flavored Markdown.
- Keep the tone "Professional yet accessible."
- For the Arabic parts, feel free to use clear Egyptian dialect for the "In Plain English/بالبلدي" sections to make it more relatable.
